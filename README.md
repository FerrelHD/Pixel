# 🕷️ Spidey Pixel // 16-Bit RPG Portfolio

> **"FERREL RASHAD // FRIENDLY NEIGHBORHOOD WEB & GAME DEV"**

A retro 16-bit RPG-themed portfolio hero section inspired by classic arcade aesthetics and [samuelrizzon.dev](https://www.samuelrizzon.dev/).

---

## 🎮 Key Features

- **Layered NYC Night Skyline**: Handcrafted retro skyline with moon, twinkling stars, lit skyscraper windows, and a flickering Daily Bugle neon billboard.
- **Pixel-Art Spider-Man Avatar**: Handcrafted SVG pixel sprite with idle breathing animation and interactive Spider-Sense warning sparks.
- **16-Bit RPG Dialogue Box**: Vintage double-beveled frame with typewriter effect and procedural 8-bit sound blips synthesized on the fly via the Web Audio API.
- **Interactive Command Menu**: `STATUS`, `MISSIONS`, `SKILLS`, and `SIGNAL` buttons with tactile 3D stepped button press physics and dedicated RPG modal windows.
- **Top HUD Display**: Player level badge (`LV.99`), health meter (`HP 100/100`), web fluid gauge (`SP 80/100`), sound toggle (`SFX: ON/OFF`), and CRT monitor scanline filter (`CRT: ON/OFF`).
- **Anti-Slop Craftsmanship**: Designed following strict `antislop` guidelines:
  - Zero em dashes in all copy and code
  - Exactly 2 core colors + 1 arcade gold accent
  - 0 dead buttons (every interactive element is fully functional)
  - 100% WCAG AA contrast compliant
  - 0 heavy audio downloads (100% synthesized chiptunes via Web Audio API)

---

## 🛠️ Tech Stack

- **Framework**: React 18 + TypeScript + Vite
- **Styling**: Tailwind CSS + Custom 16-Bit Pixel Utilities
- **Animation**: Framer Motion
- **Icons**: Lucide React
- **Audio**: Native Web Audio API Chiptune Synthesizer
- **Fonts**: `Press Start 2P`, `Silkscreen`, `VT323` (Google Fonts)

---

## 🚀 Getting Started

```bash
# 1. Clone the repository
git clone https://github.com/FerrelHD/Pixel.git
cd Pixel

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev

# 4. Build production bundle
npm run build
```
